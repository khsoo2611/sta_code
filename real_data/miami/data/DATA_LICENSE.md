# Miami housing data

MiamiHousing2016 from OpenML (data ID 43093), created by Steven C. Bourassa.

- Source: https://www.openml.org/d/43093
- License: CC BY-NC-SA as listed on OpenML, which does not give a version
  (metadata: https://www.openml.org/api/v1/json/data/43093)

Files:

- `miami_openml_43093.arff`: the file downloaded from OpenML
- `miami_openml_43093.csv`: the same data as CSV
- `miami_openml_43093_processed.csv`: made by `real_data/miami/process_data.ipynb`

The CSV files are derived from the original data and are under the same
license, so they can be used for non-commercial purposes only.
